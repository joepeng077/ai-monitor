# 公开版组件界面

1.2.0 按 2026-10-27 保留的组件信息结构独立实现界面。它与本机自用版是两套工程，版本号独立；公开版不包含本机账户读取、私有快照、助手或品牌资源。

| 样式 | 主要尺寸 | 信息结构 |
| --- | --- | --- |
| Mac 状态 | 中 | CPU 核心数、物理内存、可用存储 |
| DeepSeek 余额与五日消耗 | 中 | 余额、Flash/Pro 月费用、五日费用 |
| WorkBuddy 用量 | 大 | 积分、七日消耗、模型分布 |
| Claude 用量 | 小 | 五小时与每周额度 |
| Claude 双额度 | 中 | 两行额度电池与重置时间 |
| Claude 总览 | 大 | 双额度、Fable、重置次数、七日用量 |
| Codex 总览 | 大 | 双额度、重置次数、七日用量 |
| Codex 双限额与五日用量 | 中 | 双额度、独立重置时间、五日用量 |

Claude 额度焦点、Codex 周额度、Codex 横向周额度不在组件列表中。

## 数据与空态

账户组件的生产入口固定使用空展示模型，显示“未启用”。本次只更新布局与展示数据类型，没有增加导入入口、账号连接或自动刷新。展示类型能表达额度、费用和历史数据，并不表示这些数据已经接入。

- 未知额度、日期、重置次数和用量显示缺失态；已知的 0 保留为 0。
- 五小时、每周、Fable 分别存储，不互相替代。
- 图表使用完整自然日；缺失日期不补成零消耗。
- 套餐仅展示模型传入的有效文字，不推断或默认付费套餐。
- Mac 保留既有公开系统指标。CPU 核心数与总内存不冒充 CPU 使用率或内存占用率。
- 没有可执行的账户刷新动作，因此不放置假刷新按钮。

## 兼容与验证

原有 Codex、Claude、WorkBuddy、Mac 的公开 Widget kind 保持，新增样式使用新的 kind。既有支持的尺寸继续可用；不同尺寸采用适合该尺寸的信息布局。

验证包括 Swift 核心测试、macOS 应用与扩展编译，以及原生尺寸下的空态和虚构示例渲染。虚构示例只用于开发验证，不是用户账户数据，也不作为生产组件默认值。

签名构建或离屏渲染通过，不代表已经完成用户桌面的实际观感验收。
