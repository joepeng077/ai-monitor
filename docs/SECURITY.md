# 安全与隐私

本项目的第一公开版本只提供本机系统指标和脱敏展示模型。

## 明确不做

- 不抓取浏览器 Cookie、钥匙串、私有应用容器或日志。
- 不调用未公开的账户接口。
- 不提交真实快照、截图、账号数据、构建产物、签名证书或开发者配置。
- 不提交或分发机器专属的套餐覆盖；来源未知或无效的套餐字段必须隐藏。

## 后续适配器门禁

任何 Codex、Claude 或 WorkBuddy 自动刷新实现，都必须先满足：公开且允许的来源、用户明确启用、最小数据保存、无凭据日志、独立安全测试和条款审查。

安全问题请勿在公开 Issue 中披露账户资料；请通过仓库维护者的私密联系方式报告。
